# API Mahasiswa - Tugas Integrasi Sistem

## Deskripsi
Project ini merupakan implementasi REST API untuk mengelola data mahasiswa menggunakan FastAPI.

## Teknologi
- Python
- FastAPI
- Uvicorn

## Fitur API
- POST - Menambahkan data mahasiswa
- GET - Menampilkan data mahasiswa
- PUT - Memperbarui data mahasiswa
- DELETE - Menghapus data mahasiswa

## Data Mahasiswa
Data mahasiswa terdiri dari:
- Nama
- Alamat
- IPK
- Semester
- Hobi
